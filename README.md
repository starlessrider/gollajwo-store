# 골라줘상점

친구들에게 실제 판매를 시작하기 전에 상품 후보를 보여주고, 자연스럽게 의견과 예약 의사를 모으는 1페이지 모바일 웹 프로젝트입니다.

## 프로젝트 목적

`골라줘상점`은 쇼핑몰이 아니라 판매 전 실험 도구입니다.

- 친구들이 어떤 상품 후보에 반응하는지 확인한다.
- 가격, 구성, 포장 중 무엇이 구매 의사에 영향을 주는지 배운다.
- 칭찬보다 "왜 별로인지"를 듣는 대화를 만든다.
- 실제 판매 전 재고와 비용을 작게 유지한다.

## 페이지 구조

### 친구용: `index.html`

친구에게 공유하는 공개 화면입니다.

1. 짧은 인사
2. 상품 후보 3개
3. 빠른 반응 버튼
4. 한마디 의견
5. 예약 의사 확인

### 본인용: `coach.html`

학생 본인만 보는 준비 화면입니다.

1. 친구에게 보낼 문장
2. 보낸 기록
3. 반응 요약
4. 최근 의견 확인

## 상품 관리

상품 후보는 Google Sheet의 `Products` 탭에서 관리합니다.

- `active`: `TRUE`면 친구용 페이지에 보이고, `FALSE`면 숨겨집니다.
- `display_name`: 친구에게 보이는 상품 이름입니다.
- `price_label`: `5천원대`처럼 가격 범위만 보여줍니다.
- `item_1` ~ `item_3`: 패키지 구성품입니다.
- `image_url`: 직접 찍은 사진이나 사용 가능한 이미지 URL입니다.
- `sort_order`: 작은 숫자부터 먼저 보입니다.
- `source_url`, `cost_note`: 판매자 내부 참고용이며 친구용 페이지에는 보이지 않습니다.

## 운영 원칙

- 결제는 받지 않고 예약 의사만 확인한다.
- 실명, 주소, 전화번호는 받지 않는다.
- 처음에는 가까운 친구 10~20명에게만 공유한다.
- 반응을 보고 상품 하나만 실제 소량 준비한다.
